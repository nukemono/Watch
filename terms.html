太陽ウォッチ センサー用語ガイド

この資料は、画面やCSVに出てくる専門用語を「何を表しているか」「どう使うか」という視点でまとめたものです。

方位・姿勢

方位
スマホが水平方向のどちらを向いているかを角度で表したものです。このプロトタイプでは北=0°、東=90°、南=180°、西=270°です。
alpha / beta / gamma
スマホの3方向の回転角です。端末やブラウザで符号や基準が異なることがあるため、生データとして保存して比較します。
absolute
その方向データが地球基準の絶対方向として取得できているかを示す情報です。trueなら方位計算に使いやすく、falseや未取得なら相対回転の可能性があります。
webkitCompassHeading
主にiPhone Safariで取得できるコンパス方位です。北=0°を基準にした値として利用できます。
webkitCompassAccuracy
iPhoneのコンパス方位の推定誤差です。小さいほど方位の信頼性が高い目安になります。
deviceorientationabsolute
Android系ブラウザなどで絶対方向を取得できることがあるイベントです。

動き・加速度

加速度
スマホがどの方向にどれくらい加速しているかを表します。手ブレや急な動きの検出に使えます。
重力を含む加速度
端末の動きに加えて重力も含んだ値です。スマホの傾きや姿勢推定の材料になります。
回転速度
スマホがどれくらいの速さで回転しているかを表します。照準中の揺れや回転を検出できます。
センサー更新間隔
何ミリ秒ごとにセンサーデータが届いているかを示します。端末ごとの取得頻度比較に使えます。

位置・高度

GPS標高
位置情報APIから得られる高さです。端末や受信環境によって取得できないことがあります。
標高の推定誤差
GPS標高がどの程度ずれている可能性があるかの目安です。
水平位置精度
緯度・経度が何m程度ずれている可能性があるかを示します。
移動方向・移動速度
位置情報から得られる端末の移動状態です。静止中は取得できない場合があります。
地平線の下がり
観測者の位置が高くなるほど、幾何学的な地平線がわずかに下がる量です。現在は自動補正せず、検証用に記録しています。

端末情報

CPU論理コア数
ブラウザから取得できる端末処理能力の参考値です。端末性能差の確認用です。
端末メモリ情報
対応ブラウザで取得できる概算メモリ量です。取得できない端末もあります。
画面倍率
CSS上の1ピクセルに対して、実画面上で何ピクセル使われるかを示します。
通信状態
対応ブラウザでは通信方式、推定速度、遅延などが取得できます。
Generic Sensor API
加速度、ジャイロ、磁気、姿勢などをより直接的に取得する新しいセンサーAPIです。Android Chromeでは利用できることがありますが、iPhone Safariでは対応が限られます。

CSV内の時刻

local_time
スマホ上で見える現地時刻です。
iso_time
国際標準形式で保存した時刻です。複数端末のデータをあとで揃えるときに便利です。
epoch_ms
1970年1月1日からの経過時間をミリ秒で表した値です。時刻差を機械的に比較しやすい形式です。
